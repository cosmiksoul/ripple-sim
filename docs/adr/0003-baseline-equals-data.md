# Базовая линия равна данным: встроенные события и точное следование тренду

Реальные ряды уже содержат эффект всех реальных событий, поэтому движок не прикладывает удар события, пока оно стоит на своём месте в истории: удар получают только события, новые для данных (сгенерированные, вмешательства, всё после «сегодня»). Если в мире игрока предусловие реального события не выполнилось, его каталожный удар вычитается из тренда, чтобы убрать из данных последствия того, чего не случилось. По той же причине приращение реального ряда прибавляется к индикатору целиком, а вязкость гасит только остаточный зазор между индикатором и трендом: иначе базовая линия отставала бы от быстрых рядов на 10–25 пунктов. Альтернатива, прикладывать удары поверх данных, удваивает каждый реальный кризис; альтернатива, заранее вычитать удары из рядов, численно эквивалентна выбранному правилу, но требует препроцессинга всех рядов под каждый каталог.
