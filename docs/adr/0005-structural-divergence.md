# Когда страна существует только в одном мире: передача модели и аналог тренда

Если СССР в мире игрока дожил до 1998 года, у него нет ни реальных данных, ни реального расписания, а у его преемников есть и то и другое. Решили три правила. Расхождение страны, которая активна только в одном из миров, равно 1, поэтому для неё функции риска работают в полную силу при любой «живой истории». Реальные события её преемников делятся по группам: природа и здоровье (в каталоге обе — группа `nature`) привязаны к месту и перенаправляются тому, кто владеет территорией, с пометкой «в реальности: …»; экономика, политика и конфликт отменяются с записью «история пошла иначе», и дальнейшую судьбу страны определяет модель рисков из её собственного состояния. Тренд после реального конца страны синтезируется по аналогу: `real[t] = real[конец] + масштаб × (аналог[t − сдвиг] − аналог[конец − сдвиг])`, где аналог берётся из авторской таблицы в контенте, а без записи — из медианной траектории субрегиона. Отвергнуто: простое перенаправление всех событий преемников на предшественника (выживший СССР жил бы склейкой чужих судеб) и NaN после конца с удержанием уровня (мёртвый ряд на полвека).
